# SideQuest: required project context for Claude coding agents

Before planning, modifying or reviewing final-project code, read **[AGENTS.md](AGENTS.md)** and **[FINAL_PROJECT_AGENT_HANDOFF.md](FINAL_PROJECT_AGENT_HANDOFF.md)** in full. Check the latest master and open PR heads rather than relying on a dated snapshot.

The handoff records proposed human owners, November 21–December 2 milestones, actual code versus gated features, map artwork/data dependencies, Google Calendar/API states, integration order and test evidence. **Team assignments require their acceptance; no agent may enable unreleased Auth/group SQL, merge PRs, deploy or handle keys without authorization.**

Keep `README.md` concise and professor-facing. Put coordination updates in the handoff or owning GitHub issues, not README.
