## Professor-reviewed scope and diagram history

1. Original P3 was broader: partial attendance, time explanations, walking time, costs, rules and sharing. The team reports professor approval of a smaller P4-based MVP: **anonymous posting, shared browsing, full-fit search and device-local Schedule**. The approval was reported by the team, not independently verified in a separate written instructor artifact.
2. Professor Kandel confirmed the existing P4 diagram is correct. **P4 is approved and resolved.**
3. The selected P5 coursework ER includes USER and AVAILABILITY_WINDOW. Those are **not current M2 database tables**. Professor Kandel's M2 Part 1 requires updated CRC and ER that match the actual MVP. The implemented persistence is a shared events table and browser-local plan IDs, so the final submitted drawing needs explicit explanation of the difference.
4. Assignment and lecture deadline text differ. Confirm the applicable deadline and actual submission in the current course portal; repository checks do not establish either.

## Outstanding release gates

- **Live sharing:** configure Supabase project, apply reviewed SQL migration, verify Browser A post → Browser B discover → plan on B → remove plan without deleting public event.
- **Real access controls:** verify anon read+insert and denied update/delete; avoid secret/service-role credentials in browser or Git. All database keys now stay on the Node server. Verify the hosting environment before deployment.
- **Visual review:** open on phone width and desktop, check screen reader labels/keyboard focus, timestamps, long descriptions and empty/offline states. The Campus Index feature is preserved but separate.
- **Docs/diagrams:** use the current M2 implementation CRC/storage diagrams in this repository; share accessible links; keep M2 Part 2 reflections individually owned. Do not claim this audit alone completes those deliverables.
- **CI:** green checks for the **exact** commit merged to master. Refresh results after every merge.

This audit is an honest checklist of verified code and remaining real-world checks, not a claim of a deployed product or a grade.
