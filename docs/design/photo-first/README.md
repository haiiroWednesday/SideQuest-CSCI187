# Photo first (round 10)

Real photos lead every card. Drawings appear only when an event has no usable picture, and for empty states, the hero, and recap cards.

The full pipeline (data model, uploads, imports, moderation, display rules, build order) is in the team spec, a Claude doc: "SideQuest Event Photos: Pipeline Spec".

Screens in `shots/`:

1. Discover, photo first, drawings as backup
2. Event detail with one credited photo
3. Post: add a photo three ways (upload, paste link, keep the drawing)
4. Post: one focal point crops every shape, plus alt text
5. Post: consent, upload, a quick check for new hosts
6. Post: import from a pasted link, with credit
7. Report a photo, not the event
8. The photo check queue
9. The event menu with real thumbnails
10. A Sunday recap made of the user's photos
11. Flyers framed whole, logos as badges
12. Photos from people who went

Photos in these mockups are stand-ins: Cynthia's own (observatory, rose, fountain, grotto) and crops of saved campus screenshots. Do not ship them.
