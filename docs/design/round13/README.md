# Round 13: ideas, not layouts

Nine inventions (ID1 to ID9 on the review page, Q1 to Q9 in these files). Each changes how you use the app instead of restyling a screen. Every option is three devices: the phone, the same screen on a bad day, and a desktop.

| File | Idea |
| --- | --- |
| `shots/Q1.webp` | A stranger has a quest for you |
| `shots/Q2.webp` | The quest board, with tear-off tabs |
| `shots/Q3.webp` | Main line, side quests |
| `shots/Q4.webp` | Minutes are money |
| `shots/Q5.webp` | Departures |
| `shots/Q6.webp` | Tonight's sky |
| `shots/Q7.webp` | Rings of minutes |
| `shots/Q8.webp` | The someday bag |
| `shots/Q9.webp` | Quest complete |

**Read `CODE_IMPACT.md` before building any of these.** It checks each idea against the code on `master` as of November 16 and lists what the app would have to store first. Three run on today's data. Several statuses in the mockups have nothing behind them yet.

Sources: `o9-a.part`, `o9-b.part`, `o9-board.part`, `q9-css.txt` (picture classes), `q9-anim.css` (motion, with a reduced-motion override), `build-o9.py`. They build on the Round 12 helpers in `../round12/o8-a.part`.
