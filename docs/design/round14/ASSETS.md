# Round 14 photo cut-outs: where each one comes from

Every object in Round 14 is a photograph with its background removed. Files are in `assets/` as WebP with transparency. Backgrounds were removed with rembg (isnet-general-use model), except files that already had transparency.

## What the licences ask for

- **Public domain and CC0:** nothing required.
- **CC BY:** credit the creator. This table is that credit while the work stays a class design study.
- **CC BY-SA:** credit the creator, and share any edited version under the same licence. That covers the telescope, the date stamp, the clothespin and the baguette. Swap them for public-domain photos before any public release.
- Some photos show brand marks (the volleyball, the ticket stub). Fine for a mockup, worth replacing before anything ships.
